One patch-note line for a bug in human biology — the brain replaying old
embarrassments at 3am instead of sleeping — written in the terse register
of a real release note. Entry for the
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d)
bounty on [make.fun](https://make.fun/r/4scqj2d7).

## The patch note

> v3.1.0: fixed a bug where the brain replayed embarrassing moments from 2009 at 3am instead of sleeping.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a small deterministic Python program (no dependencies, no
network). It writes exactly one line of plain text to `/output/entry.txt`:
1–160 characters, as the bounty gate requires.
